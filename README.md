# 天工数据工作区

用角色分工、原生任务运行和独立科学复核组织生命周期评价（LCA）数据的研制与交付。

- [AGENTS.md](AGENTS.md)是项目指令入口，[角色指南](roles/README.md)和[数据原则](work/control/data-principles/PRINCIPLES-v3.md)说明各角色如何决策。
- [工作区架构](docs/workspace/architecture.md)和[业务流程](workflows/business-flow/README.md)说明范围、合同、派发、运行恢复、独审、采用与完成。
- [项目 Skills](.agents/skills)提供检索、建模、校验和审核方法。[版本锁](skills-lock.json)列出上游提交和文件哈希。
- [安装与离线验证](installation/README.md)说明如何运行仓库检查和合成测试。
- [数据开发文档](docs/data/README.md)和[数据审核流程](workflows/dataset-review/README.md)说明科学方法、对象和版本边界。

公开版省略原始项目数据、私人环境配置、历史归档、日志和实际任务记录。一些原文中的引用指向这些材料。接入外部服务需要按实际账号和用途配置。
