# 天工数据工作区

天工数据工作区用角色分工、原生任务运行和独立科学复核，组织生命周期评价（LCA）数据的研制与交付。

- [工具源码](bin/)包含工作查询、会话接续、交付记录和审核工具。
- [职责指南](roles/README.md)介绍分工和交接。
- [业务流程](workflows/business-flow/README.md)和[数据审核流程](workflows/dataset-review/README.md)介绍工作入口。
- [运行配置示例](workflows/business-flow/runtime.example.json)默认禁用远端宿主。

这是供阅读和开发参考的公开源码快照。接入真实工作区需要自行配置数据、凭据及运行环境。仓库中的内部资料链接可能需要原工作区才能打开。
