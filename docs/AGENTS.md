# 修改跨任务文档

查规则时，从[文档目录](README.md)直接打开所需页面。编辑时，数据命名和分类归 `data/`，共享命令归 `tools/`，工程结构及材料保管归 `workspace/`。某个包的试算、采用理由或平台回执留在原包，从说明页引用它。

改一项规则，先找谁批准了哪份正文。批准记录已经写死路径和哈希时，文档、岗位说明和查询命令共同链接这一份原件。改名或移动前查出所有引用者，核旧入口能否读到原件。更新后从对应 Role、工作流程和公开命令分别走一次。例如改命名规则读[原试行依据](data/naming.md)，改数据原则读[获准使用的版本](data/README.md#现行数据原则)。

维护者可以用[仓库链接检查](../roles/maintainer/scripts/check_links.py)检查所有 Markdown 页面，包括改名文件的外部引用者。哪些科学结论因此改变，由负责这项数据的人复核。
