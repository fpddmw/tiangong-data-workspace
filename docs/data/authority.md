# 数据操作的权限与恢复

- **入库硬边界。** 数据库仅接纳已声明研究边界内、具备可核对物料与能源实物输入输出的单元过程数据（中国地域须有实际依据），并须满足来源限制。缺乏透明实物投入清单、仅报告单指标（如仅 GHG）分阶段/汇总结果的文献，即使为中国数据亦仅作本地 Benchmark/PCR 对照，禁入天工；欧洲数据、ELCD 等受限聚合背景及可能收费或产生版权问题的数据库来源亦禁入天工。改名、换 UUID、改中国地域或单元过程/LCI 标签均不能绕过。此规则优先于一般草稿保存授权；写前读取[入库硬边界](rules.md#database-admission)与 `policy.data_admission`。既有对象只读核查，删除仍由用户执行。
- **单 UUID 最新活跃版本主线。** 研制、修订、缺口统计与 2.0 基线按 UUID 仅维护唯一最新活跃主线（`policy.data_lifecycle`）；严禁将未过科学复核与质量门禁的 `state=0` 后继草稿盲推为 `100` 覆盖公开旧版。
- **原任务与写责。** 原生 Task、attempt、平台审核和真实交接各保有原事实；[业务入口](../../workflows/business-flow/README.md)记录当次委派、返回和采用决定。每个精确对象一位写者。远端动作核当前账号、项目、具名范围、所有权、状态、前像及原生检查，执行后完整读回。
- **具名授权。** 发布、删除、已发布正文原位变更、他人数据／跨账号写入及新远端计算分别核当前精确授权；合格本人活动草稿适用当前 P4。未具名批量写入、基本流、LCIA 方法和 CF 变更保持关闭，具名例外核原授权范围。
- **恢复与凭据。** 保全原证据、运行绑定、安装、凭据和历史回执。结果未知沿原尝试恢复；暂停或停止仅按原授权恢复。历史 `next_action` 供查证。账号和数据凭据留在原拥有者。
- **修正与维护。** 本次输入和调用由原作者修正。本工作区共享工具、运行时、Hook 与脚本问题随[原任务返回](../../workflows/business-flow/README.md#维护发现的正常接续)交指定维护者，由[维护者](../../roles/maintainer.md)在本仓直接复现、修复并验证原工作链；天工系列上游仓库（CLI/Foundry/Platform/Worker 等）的能力缺陷默认以脱敏英文 Issue 为先并跟踪官方新版本接入，未经用户另行具名委派不发起上游实现或 PR。
