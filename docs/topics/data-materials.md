# 数据材料导航

数据库拥有已保存Process/Flow/Source正文和身份；本地只保管尚无其他可靠拥有者的证据、作者输入、推导与原提交记录。本页不建立数据库副本，也不要求每个UUID分配本地目录。

- [已整理的跨对象原材料](../../projects/data-library/README.md)：原候选、账号历史观察和来源核查；路径保留实际绑定，data-library不再表示数据权威或强制新家。
- [2026-11-09 Flow 参考属性归一化](../../materials/packages/flow-reference-normalization-20261109/README.md)：108,371个可见版本检查、8条公开异常；11-10五个后继已公开，本轮具名1,089个Process/1,165条引用全部迁移。原49个在审版本经50条原生退回后保留同版草稿，历史意见保全；两条外部Root依赖的恢复审核仍受原科学/关系检查阻断。PR470按用户决定移交，实际结果与接续以原包为准。
- [电力目标与原材料](electricity.md)、[废水主题](wastewater.md)：引用适用共享对象。
- [外部导入原任务](../../projects/external-imports/README.md)：保留活动来源包和USLCI原位置，不能因分类而中断。
- [数据生命周期](../data/dataset-lifecycle.md)：实际状态、账号和操作路径决定准入；材料目录不授权。

先找原Task/brief/包。只有缺保管位置的新作者材料才推荐到materials/packages；新增整体验收条件才需要projects目标。完整规则由[NAVIGATION](../../NAVIGATION.md)维护。
