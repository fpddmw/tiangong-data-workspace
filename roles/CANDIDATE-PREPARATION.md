# 候选准备 A01–A03

从[原工作包](data.md)取用途、参考产品、对象范围和终点。用一份完整正文完成映射、检查和独审，使保存时核验的是同一个候选。

## Choose the current working body

1. **找原接续。** 从原包取写者、Task／attempt、最近成功的完整保存读回、已接受的未保存候选。写入结果未知时先沿[原尝试](../workflows/dataset-review/保存与读回.md#恢复原尝试)核效果。
2. **取得适用前像。** 用已获准的入口读精确当前正文和 owner／state，辨认公开基线与所派固定草稿。复用当前工作已取得的有效读回；相关正文或依赖变动后刷新，写前再核前像。版本、时间戳和来源标题只供定位。
3. **对齐三份正文。** 用同一完整投影和规范哈希比较当前线上、上次完整读回与接受的未保存稿。当前已经包含拟修正内容时，复用成功并转查余项。差异交原写者核合并，保留未受影响的已审科学。上线读不到时，说明本次分析依据哪份历史正文及可见性限制，继续独立证据工作。
4. **绑定选中的正文。** 在原 brief 或候选给出类型、UUID、版本、完整投影／哈希、owner／state、观察时间、原读回及适用目的。独审查看选择和受影响的差异。已有候选和源账时逐条对账，沿原包补有依据的差额。

## 完整组装

1. **取实际合同与适用 Skill。** [工具入口](../LOCAL_TOOLS.md#按工作选择技能)区分现有草稿、直接构建、受管 Foundry 和 Model。用当前原生上下文、schema、模板和绑定，按原任务记录实际采用的语义决定。直接 CLI 使用公开输入合同；Foundry 延续当前 Task 的已索引工作项与公开后继。
2. **先对齐量和身份。** 按[核分母与参考量](#核分母与参考量)给每项交换标原量、期间、标准单位及同一参考分母。锁定产品规格、参考 Flow／属性／单位和有效方向。核缺的是直接 Flow、适配供方还是本次选供；缺供走[按需诊断](../workflows/dataset-review/README.md#例外分支)。共享 Flow 先按[相容需求](COORDINATION.md#shared-flow-decisions-before-uuid-allocation)决定一位写者。名称按[四字段约定](../docs/data/naming.md)落进实际 brief 和完整正文，分类按[实际目录](../docs/data/classification.md)核层级。
3. **固定身份和构建。** 已有或导入对象使用 preserve 保留精确 UUID／版本。确定新建后，用[合格初始化入口](../docs/tools/candidate-initialization.md)分配一次身份、初始版本和固定输出，后续复用；若所绑 CLI 缺该能力，保留缺口。优先使用 SDK 支持的 builder。实际路线接收外部完整种子时，按同一序列化跑 SDK 严格校验；科学含义由原作者及独审验证。
4. **给整包配支撑。** 将新改 Flow／Source 完整正文和身份加入同一候选。对它们先做本地语义和单位检查，在线资格待原写者保存并读回后检查。缺少这些在线事实时记录为待办。现有在线依赖按精确版本、状态和物理适配选用，使用原生引用意图和可复用证据。
5. **转门禁。** 在原包交接正文、相关依赖、适用合同和差异，[一次运行适用机器检查](../workflows/dataset-review/门禁与引用检查.md)。只换 descriptor、seal 或文件绑定时，由原写者重做原生绑定，科学内容相同可复用已有独审。内容、依赖语义或运行行为改变时重核受影响的结论。

## 核分母与参考量

先确认来源的物理活动与数量基准，再按精确参考 Flow、属性、单位组和因子换算。列出原数量、分母、单位与输出范围，把同一分母用于所有受影响交换。替代分母需要注明适用目的，保留独立原量。

同样标 kg 的交换也可能按成分含量计，沿实际参考属性链确认。分母有争议时，给出各口径支持的用途和受影响的量。按需查[原案例及计算依据](../docs/workspace/knowledge.md#原案例)，原 HTAM 方法可用 `context.py --method htam-note:research-methods:cf2d8d1fc08c` 展开完整条件和反例。

## Process annual quantity and Platform round trip

编写 Process 或回验编辑器保存时，先在原包固定年度量含义与精确参考单位，直接在原生年度字段表达数字、单位与上下文；年度期间、推导保留在相应方法字段，用途说明使用规范 useAdvice 字段。字段格式以当前 SDK 为准，科学依据由作者与独审核实。按[年度量与方法字段](../docs/data/process-platform-fields.md#按实际路线选择年度表示)选择真实来源、固定假设或原生缺证路线；完整读回复用该页映射。工具冲突保留原输入、Platform 正文和原报告，交维护者处理；有独立依据的工作继续。
