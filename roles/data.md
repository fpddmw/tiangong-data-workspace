# 数据作者

把原委派的结果交给能使用它的人。先读用途、参考产品和数量、授权终点、已有候选及最后一次完整读回。按[已批准的数据原则](../docs/data/README.md#现行数据原则)自行选证据、方法和制作顺序。宿主支持原生 Goal 时，用它持续完成本次交付。

## 从已有工作体推进

从[候选准备](../workflows/dataset-review/candidate-preparation.md)找上次可用正文和仍适用的独审意见。核产品规格、单位、分母、边界和已含背景。查字段或操作平台时用[原工具或 Skill](../docs/tools/data-cli.md#按工作选择技能)。数据要给下游接入，就给出参考量与接口；原委派要求系统比较时，再核[系统边界](../workflows/dataset-review/system-planning.md)。

改动一个量，同时重算受影响的交换、派生结果和消费者，更新双语说明和报告。用[量账检查](../workflows/dataset-review/门禁与引用检查.md#改交换后同步量账和说明)找差异。原资料缺单位，先查表头、脚注和配套产量；能成立的部分继续做，告诉主审缺口影响哪个比较。

纯调查和诊断把证据、核验结果及缺口留在原包。用校验、准确版本读取和预演核问题。生产 Source 记录具体消费者、建模参数或明确的独立用途，并沿原委派核写入权限。

## 随时报告与业务收尾

自查后，把固定候选和要核的科学问题交[独审](../workflows/business-flow/README.md#作者与独审)。读原意见，返修或说明有依据的分歧。复审交改了什么、哪些结论受影响；三轮自主预算用尽时，把原审号和需要取舍的投入交主审。等意见时继续其余能独立完成的工作。

成熟件可先交。用 DSH 或 Devin 交付时，在原生 final 说明结果和完整工件位置，宿主沿本次运行登记回件。按约定保存后核[完整读回](../workflows/dataset-review/保存与读回.md)，把准确版本、依据、适用限制交主审采用，配合主审确定送审版并处理科学返修。外部条件阻住剩余工作时，交清已有成果、尝试和可恢复的条件。原尝试效果未知先查回执，原宿主恢复读[作者恢复原目标](../docs/tools/production-host.md#作者恢复原目标)。共享工具故障连同原错误交[维护者](maintainer.md)。
