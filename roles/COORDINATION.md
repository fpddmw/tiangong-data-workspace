# 责任、派工与交接

所有 agent 在同一工作目录直接读完整 brief 和原件。主审对整个任务交付负责，给清用途、对象、授权和终点，持续解决依赖、接回成果并推进平台送审。worker 在原 Session/Goal 中自主完成方法选择、取证、制作、自查、科学独审和返修。每个精确数据对象保持一位实际写者，交接时核当前版本及在途效果。

## 用途与四种边界

| 边界 | 需要交清的结果 | 原责任 |
|---|---|---|
| 数据库版本覆盖 | 本版承诺的产品、技术、地域、时间和用途组合及投入增益 | 总主决定，主审提供覆盖证据 |
| 产品系统 | 声明核算/比较所需的活动、方法、依赖及合理终止位置 | 系统负责人和科学作者，受父目标约束 |
| Process模块 | 本条包含的物理活动、参考产品、输入输出及已聚合背景 | 作者判断、独审评估、主审按用途采用 |
| 工作包责任 | 本包制作/复用什么，交清哪些相邻接口，达到哪个终点 | 原委派者和主审给完整结果，作者自主交付 |

沿原合同表达：`purpose`交清使用者及新增描述/计算/比较能力；`scope_boundary`分别说明本版承诺、本包负责与相邻排除；`interfaces.text/refs`保管物理规格、计量、已含背景、已核复用及待承接者/返回点；`acceptance.text/refs`给用途判断及交付依据；`endpoint`和`authority_refs`分别记录终点与真实授权。四种边界可以不同，使用同一合同正文与原件，不新增字段或另写合同副本。

有限子包达到终点后可以结束，父目标尚欠的必要部分仍由主审承接。范围缩减/替代取原委托者的明确决定；“有限用途”、全部返回或登记缺口都不自行撤销父承诺。程序核已登记范围、身份、版本、采用和终点；漏录活动、适配与科学充分性由科学agent对照用途判断。

## 作者、独审与主审

作者自查后明确请求科学独审，固定所选候选及科学问题。独审使用独立只读 Session，读取原件并可做离线计算，用普通文字直接反馈作者；同模型家族允许。作者自行返修、复核或有据解释分歧，持续完成包内工作。主审按一份合同读完整实际成果及条件，调用同一集中检查决定阶段/最终采用及后续投入，接手成熟候选的正式平台送审并核实回执。送审后由[轮询维护者](platform-feedback.md)定期归集平台意见，按包汇总给主审。

采用、任务决定和原生执行分别保存。worker 返回后，主审把实际成果对回原范围和当前计划，安排全部未达终点的责任，包括已承担未交付、有返回待采用、待核关联及尚未开展项；原调用已终结且仍有包内工作时，明确说明剩余交付并接续原 Session。覆盖、余项、责任或投入判断变化时更新原计划，纯运行事实沿原回执读取。阶段采用记录用途，整个任务的完成按原目标核实。范围或授权变化由负责人写入原任务，明确停止与恢复也由负责人按原事实决定。公开命令见[业务入口](../workflows/business-flow/README.md)。

## 运行与恢复

启动、接续、观察和停止使用[原生运行入口](../docs/tools/production-host.md)。同一作者复用原Session；独审是与作者调用寿命解耦的独立OS作业，原review_id可持续取件。宿主记录真实身份和完整报告，管理字段及来源显示缺失不否定原文结果。未知远端操作沿原 attempt 查询，不重新发送；原停止意图保留。

跨负责人交接必须有实际授权，先确认原写者及在途效果；更换显示名、任务名或超时不能建立新写责。保存原交接依据，明确实际新负责人，原凭据不转给其他角色。旧会话事实可查，旧协议不继续执行。

## 共享依赖与维护

消费者核原版本、用途和限制；缺少某项只影响依赖它的判断，其余工作继续。共享 Flow 按物理含义、规格、物态及参考属性比较后复用准确身份，原写者保管变更，见[系统规划](SYSTEM-PLANNING.md)。

必要依赖留在消费者原scope和当前计划，以原`requirement/deliverable`、`source_refs`和合同interfaces链接准确供方、写者与返回点。同Task沿现有links承接；跨Task保留双方原引用和实际责任，不能借别包请求冒名关联。相容的共享供方建设一次，各消费者独立读取准确版本并作本方采用；已派出、已报board或供方完成仍不代替消费者采用。新必要需求由负责人有据增量登记，不由程序从自然语言猜出。

共享故障交[维护者](maintainer.md)亲自修公共能力，沿原 board 回验。工程委派与跨聊天通知按当前用户指示执行。反馈与交付沿原任务保存，维护结果由原负责人据实际回验采用。

阶段报告任何时候可返回；三类业务收尾与五种终点见[统一入口](../workflows/business-flow/README.md#随时返回采用与完成)。原生Goal、一次turn、报告、主审整包完成分别记录。当前计划按实质变化就地更新有效安排，历史和技术流水由原账本/原件保管。Hook提供短事实和完整入口，不唤醒聊天或替agent派工；未展开不表示没有条件。
