# 原业务活动入口

当前职责从[角色入口](README.md)和原委派读取；本页保留活动名称的定位，不另定义交付条件。原任务决定用途与终点，平台账号及原写者保有实际权限。

<a id="todo"></a>
## TO DO：发现与排序

[总主](global-main.md)选择有价值的完整包和投入；跨包系统依赖按需读[系统规划](../workflows/dataset-review/system-planning.md)。复用原请求、证据和在途工作；相似名称或同一个需求键只帮助定位，科学等价由 agent 核实。

<a id="plan"></a>
## Plan：持续负责与维护原计划

[主审](task-lead.md)维护原任务的一份当前计划，决定用途采用和后续投入。目标、授权与写责的变化保留原决定；原文登记和任务动作见[业务入口](../workflows/business-flow/README.md)。

<a id="data-editor"></a>
## data-editor：完成约定科学交付

[作者](data.md)自主推进完整包，[科学方法](../workflows/dataset-review/README.md)提供适用检查。成熟候选的获准[平台送审](../workflows/dataset-review/送审准备与实际送审.md)由主审接手。

<a id="review-feedback"></a>
## review-feedback：处理实际意见

[轮询维护者](platform-feedback.md)沿原审核读取意见和变更，定期按包汇总给主审。确有后续业务动作时，由有权负责人沿原委派接续。
