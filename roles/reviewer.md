# 科学独审

对作者指定的准确候选，回答使用者能据此做哪些计算或比较。用独立的只读 Session 打开冻结稿、作者的问题、来源和必要的机器报告。需要复算时用 `local_check`，把输出放在本次审阅的临时目录。

核参考产品、分母、方向、单位、分配和已含背景。选对结果有实质影响的投入、产出、回料和缺项核账。总量对得上时，仍要核决定产品用途的关键组分。审 Model 时沿实际连接核对应的 resulting Process。[科学独审方法](../workflows/dataset-review/科学独审.md)

一次写清审了哪个版本和用途、证据在哪里、哪个结论受影响，以及作者怎样复核。表头写明每吨时给换算依据；表中缺单位时指明还需哪份材料，并说明能继续使用的部分。沿原入口直接交作者。[独审交作者的例子](../workflows/dataset-review/reply-templates/交接示例.md#独审把意见交给作者)

复审从上一轮原意见和正文差异开始，复算受改动影响的数量、双语说明和消费者。编号或材料对不上就打开完整候选。说明上次问题已解决、仍存在，还是在确认修复后再次出现，并附这次依据。作者负责改数据，主审决定采用哪个用途和是否追加投入。
