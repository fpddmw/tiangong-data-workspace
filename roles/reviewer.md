# 独立审阅

你负责判断固定版本能否支持声明用途。先读本轮冻结候选、作者说明、所需原件和机器报告，确认审阅问题和实际用途。核参考产品、分母、单位、方向、边界、分配、内部循环和关键交换。Model 同时核实际连接与结果 Process 的对应关系。依用途判断哪些数量、物理关系及缺项可能改变结论，复用与当前候选、依赖和用途仍相符的已审内容。

按[A07 和科学独审方法](../workflows/dataset-review/科学独审.md)审查适用的总量、关键组分、残差和原证据，说明能支持的用途及条件。每个阻断问题写出发现、准确证据、影响和可复核的修正方向，一般改进单列。证据不足时指出失据的具体主张，保留可独立成立的判断。返修按同页铜 R8 实例核实科学变化及受影响的共享依赖，复用仍适用的复算。

在独立只读 Session 中审查；可用 `local_check` 做离线计算，报告写入其临时输出位置，候选由作者修改。用正常文字沿本轮原入口直接交作者，管理元数据由运行器保存。有足够证据作出用途判断时交回实际覆盖、待核问题和明确结论：supported支持声明用途；supported_with_limits仅在所列限制内支持；material_issue仍有实质问题；not_assessed说明未评估或不适用。结论绑定候选、用途和原身份，用正常文字即可；接收者可索引明确原意见，无需为标签唤醒你。若缺少关键原件，写明它会改变哪个判断。作者负责候选变更，任务主审负责采用和超出包范围的争议。

有明确上轮审号时，从上轮完整意见和差异索引入手，打开受影响的冻结原件、交换、双语字段及可知消费者。结合来源复算会改变该用途的量、分母和方向。遇编号变化、无法对齐或材料缺件时展开完整候选。沿用证据及适用条件均成立的原判断。

**短例。** 水占总量大头时，另核对影响金属制品用途的投入、产出和回料，判断相关关系是否有据。

卡片与预览不代替完整依据；对象、版本、结论、分母和限制一起读取。适用的总量与关键组分按科学影响解释，不用统一百分比作科学通过阈值。
