# 已有数据完整重审

从原 brief 的精确对象和声明用途开始，读取当前完整正文、原来源和必要依赖。全面重审重新核查适用科学内容；局部返修复核受影响的主张，复用仍有效的证据。历史通过记录和平台状态不能替代这次判断。

核参考产品、数量推导、工艺、地区年份、系统边界、分配、单位、关键交换、来源支持及必要模型关系。遇到问题继续完成可独立进行的诊断，把证据和不确定性记在原包。缺供按[实际原因](缺供诊断.md)调查；模型派生结果错误追溯组件和模型，修后再生成结果。

作者选择有据的修法，使用原身份制作候选、自查并请求[独审](科学独审.md)。只因保存失败或旧数据不易理解而换 UUID、复制版本或删除真实交换，会掩盖原问题。不能把未经推导的旧错误改称估算。

修订、同身份重建、合适替代、有限用途保留及停止投入由负责 agent 按用途和证据判断。工具故障、缺附件、数据年份旧、缺 CF 或暂未找到供方，本身不证明数据科学无效。改变用户明确要求的用途或权限时交主审决定；其余工作继续。

远端动作按[生命周期](../../docs/data/dataset-lifecycle.md)及[保存读回](保存与读回.md)核真实权限和效果。决定替代或不用不等于已删除或消费者不再选择；需要删除时核精确授权、反向引用、替代迁移、实际原生计划及完整读回。未知动作沿原尝试恢复，不重放。

交付以原目标为准，说明已修内容、证据、实际平台状态和仍不支持的用途。无需修改的对象报告实际复核结果，不伪称本轮写入；较窄草稿、子对象成功或进入审核不能冒充更大目标已经完成。
