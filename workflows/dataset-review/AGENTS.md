# 制作、复核或交接一份候选时

作者从原委派的使用者、参考量和最近的候选开始。在准备字段或解释差额时，从[方法目录](README.md#按当前阶段读取)选择对应方法。给独审的是这次冻结稿、用途、来源和仍需判断的问题。

独审从证据和计算判断哪些用途成立，沿原审阅把意见交回作者。作者用同一计量依据修正受影响的交换、双语说明和消费者，再交原版本差异。遇到缺单位等情况可对照[独审交作者](reply-templates/交接示例.md#独审把意见交给作者)。

主审按用途采用可用部分，交清版本、限制和原回执。另有平台送审约定时查[提交能力](送审准备与实际送审.md)。会改变原版覆盖或总投入的取舍，按[主审交使用者和委托方的例子](reply-templates/交接示例.md)说明选择与后果。交件可使用正常文字。
