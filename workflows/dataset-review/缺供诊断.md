# 缺供诊断

找不到供方是待解释的现象。先核消费者准确版本、交换、Flow 版本、参考属性、单位、数量、方向及边界。产品、废物处理、基本流、共产品和边界外活动的供给含义不同；任意交换提到某 Flow 不表示该 Process 能提供它。

核产品规格、交付状态、地区年份和技术。搜索允许范围内可复用的 Flow，按语义与接口判断适配；名称相似只提供线索。重复 Flow、误用身份或不相容版本可能造成表面缺供。纠正消费者的精确引用时保持真实数量、方向与单位换算依据；单个消费者误用不授权改写共享 Flow 的含义。

有合适供方时核它为何未入选：实际 owner/state 可见性、候选池、计算范围、地域技术过滤、模型连接、优先级及版本回落。本人草稿不在仅公开数据的计算范围内，不能据此复制 Process。核实际选边证据；未运行计算就如实记为未验证，不擅自扩大计算权限。

仅当 Flow 正确、合理搜索范围内无适配现有供方且已排除接口或选供错误时，研制必要新供方。查不到不等于全库不存在。Source/Contact 引用缺失按支撑对象处理，基本流或 CF 问题沿原数据规则处理。
