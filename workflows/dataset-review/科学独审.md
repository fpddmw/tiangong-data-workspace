# 完整候选的科学独审

用冻结候选、本次新改依赖、来源、声明用途和同一版本的机器报告作出判断。独审集中给作者实质意见，原主审决定采用。原候选、依赖和用途仍相符时复用已有审阅。

1. **参考基准与接口。** 核参考产品、分母、参考属性和单位、方向、边界、分配及内部循环。Model 同时核实际连接和派生 Process 的数量关系。逐项纠正影响用途的单位、方向、重复计量和有据量遗漏。同时对照[入库硬边界](../../docs/data/rules.md#database-admission)核验来源与形态：若候选仅源自缺乏透明物料与能源实物投入清单的单指标/分阶段汇总结果表（无论是否中国数据），须判为 `failed`（仅限本地 Benchmark/PCR 对照，不得写入天工数据库）。
2. **总量与关键组分。** 根据来源、报告和实际工段核干湿基、含水率、收率、库存、内部循环及排除项。总量接近时也核影响用途的关键组分。能源或服务的功能基准按对象边界核适用的燃料、灰渣和排放关系。
3. **残差及用途。** 存在质量残差或 CLI 提示时查明来源覆盖、计算基准和适用的物理原因。各类差额按来源不确定性、参考基准、关键交换及用途的实际影响解释。已报告量入账，来源未覆盖量说明未知及其影响。足迹缺少的相邻生产、处理或排放留作对应接口和用途条件。
4. **集中交回。** 写明候选版本、实际覆盖、证据、A07 结论及可支持的用途。阻断项给可复核的影响和修正方向，一般改进另列。返修审阅聚焦会改变原用途判断的实质变化。

例如，来源同时报告设计产能与工序产品量时，沿各自口径选择符合用途的统一分母，并说明对每单位结果的影响。

## A07 四种结论

| 结论 | 判定和下一步 |
|---|---|
| `passed` | 参考量、关键交换和适用的物理关系有据，已报告量正确进入候选，残差已有可复核解释。继续约定终点。 |
| `passed_with_documented_residual` | 仍有未知残差，已说明计算基准、来源覆盖与影响，证据支持声明的受限用途。随候选交回用途和未覆盖条件。 |
| `failed` | 关键错误、违背入库硬边界或缺证影响声明的数量、接口或用途。指出具体差额和受影响主张，按受影响用途集中修正，或保留独立可用部分并结束该项投入。 |
| `not_applicable` | 对象与边界有据地表明某项关系不适用。说明该项并完成其余适用检查。 |

P3／P4 的中间草稿允许清楚披露的较窄用途，不能把已知关键错误改称局限后直接使用。范围或内容变化时复核影响科学判断的部分，不为每个工具步骤另开独审。作者负责修订、自查、必要的再次审阅，并说明有据分歧。

按需查[原案例和证据](../../docs/workspace/knowledge.md#原案例)。保存与送审的真实权限和实际平台结果分别核[保存与读回](保存与读回.md)及[实际送审](送审准备与实际送审.md)。

主审用原 `work-dispose --apply-review … --handling …` 将原意见与处理依据关联到准确候选，按各根的用途与完成条件采用，获准时实际送审。同包未交付部分由主审继续安排。追加原 Goal 投入要对应具体新证据、科学余项或已解除的障碍。`work-check --request ID --for handoff` 集中汇集现有完整报告、准确候选、独审及作者处理；它不自动重跑科学检查或发起审阅。材料不全或局部意见仍可随时交回，其余工作继续。

## 从同一计算产生候选与说明

B02 的数据按 1,000 kg 铸棒计。作者可以在原计算脚本中从来源导出的同一百分比生成交换量及双语说明，独审可用 `local_check` 原样复算。已有计算表可直接复用。

```python
from decimal import Decimal

reference_kg = Decimal("1000")
zinc_percent = Decimal("5.5")
zinc_kg = reference_kg * zinc_percent / 100
exchange_amount = str(zinc_kg)
english = f"{zinc_percent}% zinc, {zinc_kg} kg per {reference_kg} kg of cast alloy."
chinese = f"每 {reference_kg} kg 铸棒添加锌 {zinc_kg} kg，占 {zinc_percent}%。"
```

作者随候选提交支持该口径的来源及原计算文件。确切返修可用 `prior_review_id` 指向原独审。独审核新生成的准确字段、参考量和下游含义，参考原意见已说明的适用条件。
