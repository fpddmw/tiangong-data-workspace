# 完整候选的科学独审

用冻结候选、本次新改依赖、来源、声明用途和同一版本的机器报告作出判断。独审集中给作者实质意见，原主审决定采用。原候选、依赖和用途仍相符时复用已有审阅。

1. **参考基准与接口。** 核参考产品、分母、参考属性和单位、方向、边界、分配及内部循环。Model 同时核实际连接和派生 Process 的数量关系。逐项纠正影响用途的单位、方向、重复计量和有据量遗漏。
2. **总量与关键组分。** 根据来源、报告和实际工段核干湿基、含水率、收率、库存、内部循环及排除项。总量接近时也核影响用途的关键组分。能源或服务的功能基准按对象边界核适用的燃料、灰渣和排放关系。
3. **残差及用途。** 按来源精度、计算基准和适用物理关系解释残差，核会影响用途的总量及关键组分；不用统一百分比作科学通过阈值。各类差额按来源不确定性、参考基准、关键交换及用途的实际影响解释。已报告量入账，来源未覆盖量说明未知及其影响。足迹缺少的相邻生产、处理或排放留作对应接口和用途条件。
4. **集中交回。** 写明候选版本、实际覆盖、证据、科学结论及可支持的用途。阻断项给可复核的影响和修正方向，一般改进另列。返修先从候选摘要定位改动，沿原计算和冻结稿复核受影响的量、双语说明及用途限制。相关依赖、用法和依据仍适用时，沿用已有复算与结论。

## 把意见直接交给作者

用普通文字说明结论、依据、影响和可行修正方向。证据支持的用途、未知残差、关键错误和不适用项分别按实际情况说明，给出supported、supported_with_limits、material_issue或not_assessed的明确科学含义及条件，用正常文字即可。接收者可用`work-review-record`一次索引明确原意见，身份与冻结候选自动继承，不需重启审阅者补格式。作者负责修订、自查、必要的再次审阅，并说明有据分歧。

P3／P4 的中间草稿允许清楚披露的较窄用途，不能把已知关键错误改称局限后直接使用。范围或内容变化时复核影响科学判断的部分，不为每个工具步骤另开独审。

按需查[原案例和证据](../../docs/workspace/knowledge.md#原案例)。保存与送审的真实权限和实际平台结果分别核[保存与读回](保存与读回.md)及[实际送审](送审准备与实际送审.md)。

主审用原 `work-dispose --apply-review … --handling …` 将原意见与处理依据关联到准确候选，按各根的用途与完成条件采用，获准时实际送审。同包未交付部分由主审继续安排。追加原 Goal 投入要对应具体新证据、科学余项或已解除的障碍。`work-check --request ID --for handoff`集中汇集现有完整报告、准确候选、独审及作者处理；它不自动重跑科学检查或发起审阅。材料不全或局部意见仍可随时交回，其余工作继续。
## 从同一计算产生候选与说明

B02 的数据按 1,000 kg 铸棒计。作者可以在原计算脚本中从来源导出的同一百分比生成交换量及双语说明，独审可用 `local_check` 原样复算。已有计算表可直接复用。

```python
from decimal import Decimal

reference_kg = Decimal("1000")
zinc_percent = Decimal("5.5")
zinc_kg = reference_kg * zinc_percent / 100
exchange_amount = str(zinc_kg)
english = f"{zinc_percent}% zinc, {zinc_kg} kg per {reference_kg} kg of cast alloy."
chinese = f"每 {reference_kg} kg 铸棒添加锌 {zinc_kg} kg，占 {zinc_percent}%。"
```

作者随候选提交支持该口径的来源及原计算文件。确切返修可用 `prior_review_id` 指向原独审。独审核新生成的准确字段、参考量和下游含义，参考原意见已说明的适用条件。
